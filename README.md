# 🍑 BOOTY BUMP 3D · 맨해튼 엉덩이 헌터

**Three.js 1인칭 3D** 코믹 캐주얼 게임. 황혼의 맨해튼을 걷다 앞의 **꽃미남 카툰 캐릭터**를 손으로 직접 잡고 콤보 점수를 쌓아요. 설치 없이 브라우저로 바로 플레이.

> 등장인물은 전부 100% 만화 캐릭터입니다. 가볍게 웃으며 즐기는 코믹 게임이에요 😎

## 실행 방법
`index.html` 을 브라우저로 열거나, GitHub Pages 주소로 접속:
`https://crossnam-coding.github.io/Ros-Code-Project/`

**1인칭 시점** — 나(여자)는 안 보이고 화면 아래 **내 손**만 보여요. 맨해튼을 걷다 앞의 꽃미남을 발견하면 손을 뻗어 직접 잡습니다.

## 모드
- 🗽 **맨해튼 거리** — 1인칭으로 맨해튼을 걷다 앞의 꽃미남 엉덩이를 *팡!* (60초)
- 📸 **AR 모드** — 카메라 위에 내 손 + 꽃미남이 나타나요. 탭해서 잡기! (권한 거부 시 만화 배경, 45초)

## 규칙
- 남자가 **안 볼 때** 탭하면 성공 (일반 +50, 👑 황금 +120)
- 남자가 **뒤돌아볼 때(👀)** 잡으면 *딱 걸림!* — 콤보 끊기고 -40점
- 4콤보마다 점수 배수 증가 🔥 / 점수 랭크: 🐣 → ✨ → 💖 → 👑 → 💎

## 특징
- **Three.js 진짜 3D** — 절차적(canvas) 머티리얼, 황혼 조명, 블룸·비네팅·필름그레인, ACES 톤매핑
- 캐릭터·도시·손 모두 코드로 생성(외부 모델/텍스처 없음)
- 발견 시 엉덩이 줌인 💓 / 잡으면 말랑 스쿼시 + 깜짝 반응 😲
- 1인칭 손은 카메라에 붙어 화면 아래에서 뻗어 나가요
- WebAudio 효과음·음소거, 모바일 터치 / 데스크톱 클릭 지원

## 기술 메모
- 단일 `index.html`. Three.js는 CDN(ES 모듈 + import map)으로 로드 → GitHub Pages 그대로 배포 가능.
- AR 모드는 투명 렌더러를 카메라 영상 위에 합성(내 손 + 꽃미남만 표시).
