# 🎵🍑 BOOTY BUMP · 맨해튼 리듬

**Three.js 3D 리듬 게임.** 황혼의 맨해튼 하이웨이로 **꽃미남 엉덩이들이 3개 레인을 따라 박자에 맞춰** 다가와요. 손(또는 탭)을 그 레인에 맞춰 박에 터치! 설치 없이 브라우저로 바로 플레이.

> 등장인물은 전부 100% 만화 캐릭터입니다. 가볍게 웃으며 즐기는 코믹 게임이에요 😎

## 실행 방법
GitHub Pages 주소로 접속: `https://crossnam-coding.github.io/Ros-Code-Project/`
(Three.js를 CDN으로 불러오므로 인터넷 연결 필요. 손 인식은 **Chrome/Safari**에서, 카카오톡 등 인앱 브라우저는 카메라가 막혀요.)

## 모드 (둘 다 리듬, 60초)
- 🎵 **손 인식 (카메라)** — 전면 카메라에 손을 비추고 **좌·우로 움직여** 오는 레인을 맞춰요. (MediaPipe 핸드 트래킹, 실패 시 탭 폴백)
- 🎵 **탭** — 엉덩이가 오는 **레인**을 박자에 맞춰 탭.

## 규칙
- 엉덩이가 **히트라인**에 닿는 순간 내 손이 그 레인에 있으면 **터치 성공** (일반 +50, 👑 황금 +120)
- 👀 **쳐다보는 놈**의 레인에 손이 있으면 *딱 걸렸어!* 감점 — 그 레인은 **피하기**
- 4콤보마다 점수 배수 🔥 / 랭크: 🐣 → ✨ → 💖 → 👑 → 💎

## 특징
- **Three.js 진짜 3D 하이웨이** — 절차적(canvas) 머티리얼, 황혼 조명, 블룸·비네팅·필름그레인, ACES 톤매핑
- WebAudio로 비트(킥·하이햇·베이스) 생성, 도시·캐릭터·손 모두 코드로 생성(외부 에셋 없음)
- **실시간 손 인식**: 카메라는 화면에 안 보이고(맨해튼이 배경) 손 입력으로만 사용

## 기술 메모
- 단일 `index.html`. Three.js + MediaPipe(tasks-vision)는 CDN(ES 모듈 / 동적 import)으로 로드 → GitHub Pages 그대로 배포.
- 손 인식 실패/미지원 시 화면의 손 + 탭으로 자동 폴백.
