# 🍑 BOOTY BUMP! (엉덩이 팡팡)

미국 만화풍의 코믹 캐주얼 게임. 지나가는 **꽃미남 카툰 캐릭터**를 탭해서 "팡!" 붙잡고 콤보 점수를 쌓아요. 설치 없이 브라우저로 바로 플레이.

> 등장인물은 전부 100% 만화 캐릭터입니다. 가볍게 웃으며 즐기는 코믹 게임이에요 😎

## 실행 방법
`index.html` 을 브라우저로 열거나, GitHub Pages 주소로 접속:
`https://crossnam-coding.github.io/Ros-Code-Project/`

**1인칭 시점** — 나(여자)는 안 보이고 화면 아래 **내 손**만 보여요. 맨해튼을 걷다 앞의 꽃미남을 발견하면 손을 뻗어 직접 잡습니다.

## 모드
- 🗽 **맨해튼 거리** — 1인칭으로 맨해튼을 걷다 앞의 꽃미남 엉덩이를 *팡!* (60초)
- 📸 **AR 모드** — 카메라 위에 내 손 + 꽃미남이 나타나요. 탭해서 잡기! (권한 거부 시 만화 배경, 45초)

## 규칙
- 남자가 **안 볼 때** 탭하면 성공 (일반 +50, 👑 황금 +120)
- 남자가 **뒤돌아볼 때(👀)** 잡으면 *딱 걸림!* — 콤보 끊기고 -40점
- 4콤보마다 점수 배수 증가 🔥 / 점수 랭크: 🐣 → ✨ → 💖 → 👑 → 💎

## 특징
- 단일 HTML 파일, 외부 이미지 없음(캐릭터는 전부 SVG로 그림)
- WebAudio 기반 효과음, 음소거 토글
- 모바일 터치 / 데스크톱 클릭 모두 지원
